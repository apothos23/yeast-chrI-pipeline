# dna2protein

Pipeline Βιοπληροφορικής για την ανάλυση του χρωμοσώματος I της ζύμης (*Saccharomyces cerevisiae*). Το project χρησιμοποιεί την αλληλουχία DNA και το αρχείο annotation (GTF) για να υπολογίσει βασικά στατιστικά του χρωμοσώματος, να εξαγάγει τις κωδικές αλληλουχίες (CDS), να τις μεταφράσει σε πρωτεΐνες, να συγκρίνει τις πρωτεΐνες με BLAST και να δημιουργήσει γραφήματα.

## 1. Περιεχόμενα του project

```text
dna2protein/
├── data/
│   ├── chrI.fa
│   └── chrI.gtf
├── scripts/
│   ├── step1_stats.py
│   ├── step3_all_genes.py
│   ├── step4_proteins.py
│   ├── step5_blast_filter.py
│   └── step6_plots.py
├── results/
└── run_all.sh
```

- `data/`: Τα αρχικά βιολογικά δεδομένα.
- `scripts/`: Τα επιμέρους προγράμματα Python.
- `results/`: Τα αρχεία και τα γραφήματα που παράγονται από την ανάλυση.
- `run_all.sh`: Το Bash script που εκτελεί διαδοχικά τα βήματα του pipeline.

Το Βήμα 2 της αρχικής εκφώνησης (εξαγωγή δύο γονιδίων μεμονωμένα) είναι εκπαιδευτικό/χειροκίνητο και δεν εκτελείται από το `run_all.sh`.

## 2. Απαιτήσεις

Απαιτούνται:

- Python 3.12
- Biopython
- pandas
- matplotlib
- BLAST+ (`makeblastdb` και `blastp`)
- Conda ή Miniconda

## 3. Δημιουργία περιβάλλοντος

Δημιούργησε το Conda environment με τις απαιτούμενες βιβλιοθήκες και εργαλεία:

```bash
conda create -n dna2protein python=3.12 biopython pandas matplotlib blast -c conda-forge -c bioconda
```

Ενεργοποίησέ το:

```bash
conda activate dna2protein
```

## 4. Λήψη των δεδομένων

Από τον κεντρικό φάκελο του project, δημιούργησε τους απαραίτητους υποφακέλους:

```bash
mkdir -p data scripts results
```

Κατέβασε τα αρχεία εισόδου:

```bash
BASE="https://raw.githubusercontent.com/nf-core/test-datasets/rnaseq/reference"

curl -L -o data/chrI.fa "$BASE/genome.fasta"
curl -L -o data/chrI.gtf "$BASE/genes.gtf"
```

Τα αρχεία `chrI.fa` και `chrI.gtf` πρέπει να βρίσκονται μέσα στον φάκελο `data/` πριν από την εκτέλεση του pipeline.

## 5. Εκτέλεση του pipeline

Άνοιξε το Terminal και πήγαινε στον κεντρικό φάκελο `dna2protein`:

```bash
cd /διαδρομή/προς/dna2protein
```

Ενεργοποίησε το περιβάλλον:

```bash
conda activate dna2protein
```

Έπειτα εκτέλεσε:

```bash
bash run_all.sh
```

Το `run_all.sh` εκτελεί τα παρακάτω βήματα με τη σειρά:

1. Διαγράφει τον προηγούμενο φάκελο `results` και δημιουργεί έναν καινούριο.
2. Εκτελεί τα `step1_stats.py` και `step3_all_genes.py` για τα στατιστικά του χρωμοσώματος και την εξαγωγή/καταγραφή των γονιδίων.
3. Εκτελεί το `step4_proteins.py` για τη μετάφραση των CDS σε πρωτεΐνες.
4. Δημιουργεί βάση δεδομένων πρωτεϊνών με το `makeblastdb` και εκτελεί συγκρίσεις all-against-all με το `blastp`.
5. Εκτελεί το `step5_blast_filter.py` για το φιλτράρισμα των αποτελεσμάτων BLAST.
6. Εκτελεί το `step6_plots.py` για τη δημιουργία των γραφημάτων.

**Προσοχή:** Το `run_all.sh` περιλαμβάνει την εντολή `rm -rf results`. Κάθε φορά που εκτελείται, διαγράφει τον υπάρχοντα φάκελο `results` μαζί με όλα τα περιεχόμενά του και τον δημιουργεί ξανά. Αποθήκευσε αλλού οποιαδήποτε αποτελέσματα θέλεις να διατηρήσεις.

## 6. Παραγόμενα αποτελέσματα

Τα αποτελέσματα αποθηκεύονται στον φάκελο `results/`. Με βάση τα βήματα του project, περιλαμβάνουν:

- Στατιστικά του χρωμοσώματος, όπως το μήκος, τις συχνότητες των βάσεων A/C/G/T και το ποσοστό GC.
- Αρχεία FASTA με τις εξαγόμενες κωδικές αλληλουχίες (`cds.fa`) και τις μεταφρασμένες πρωτεΐνες (`proteins.fa`).
- Πίνακες με πληροφορίες για τα γονίδια και τις πρωτεΐνες.
- Τη βάση δεδομένων BLAST και το αρχείο ακατέργαστων αποτελεσμάτων `blast_all_vs_all.tsv`.
- Τα φιλτραρισμένα αποτελέσματα BLAST, σύμφωνα με την υλοποίηση του `step5_blast_filter.py`.
- Γράφημα GC content κατά μήκος του χρωμοσώματος, με παράθυρα 5.000 βάσεων.
- Ιστόγραμμα της κατανομής των μηκών των πρωτεϊνών.

Τα ακριβή ονόματα των πινάκων, των φιλτραρισμένων αποτελεσμάτων και των εικόνων καθορίζονται από τα αντίστοιχα Python scripts.

## 7. Αναπαραγωγιμότητα

Για να ελεγχθεί ότι το pipeline μπορεί να δημιουργήσει τα αποτελέσματα από την αρχή:

1. Εκτέλεσε το `bash run_all.sh`.
2. Έλεγξε τα αρχεία που δημιουργήθηκαν στον φάκελο `results/`.
3. Εκτέλεσε ξανά το `bash run_all.sh`. Το script θα διαγράψει τα προηγούμενα αποτελέσματα και θα τα δημιουργήσει εκ νέου.
4. Σύγκρινε τα αποτελέσματα των δύο εκτελέσεων.

Η αναπαραγωγιμότητα προϋποθέτει ότι χρησιμοποιούνται τα ίδια αρχεία εισόδου, οι ίδιες ρυθμίσεις και συμβατές εκδόσεις των εργαλείων.
