# dna2protein

Bioinformatics pipeline for analyzing chromosome I of yeast (*Saccharomyces cerevisiae*). The project uses the DNA sequence and annotation file (GTF) to calculate basic chromosome statistics, extract coding sequences (CDS), translate them into proteins, compare the proteins with BLAST, and generate plots.

## 1. Project contents

```text
dna2protein/
├── data/
│   ├── chrI.fa
│   └── chrI.gtf
├── scripts/
│   ├── step1_stats.py
│   ├── step3_all_genes.py
│   ├── step4_proteins.py
│   ├── step5_blast_filter.py
│   └── step6_plots.py
├── results/
└── run_all.sh
```

- `data/`: Source biological data.
- `scripts/`: Individual Python programs.
- `results/`: Files and plots generated by the analysis.
- `run_all.sh`: Bash script that runs the pipeline steps sequentially.

Step 2 of the original assignment (extracting two genes individually) is educational/manual and is not executed by `run_all.sh`.

## 2. Requirements

Required:

- Python 3.12
- Biopython
- pandas
- matplotlib
- BLAST+ (`makeblastdb` and `blastp`)
- Conda or Miniconda

## 3. Creating the environment

Create the Conda environment with the required libraries and tools:

```bash
conda create -n dna2protein python=3.12 biopython pandas matplotlib blast -c conda-forge -c bioconda
```

Activate it:

```bash
conda activate dna2protein
```

## 4. Downloading the data

From the project’s root directory, create the required subdirectories:

```bash
mkdir -p data scripts results
```

Download the input files:

```bash
BASE="https://raw.githubusercontent.com/nf-core/test-datasets/rnaseq/reference"

curl -L -o data/chrI.fa "$BASE/genome.fasta"
curl -L -o data/chrI.gtf "$BASE/genes.gtf"
```

The `chrI.fa` and `chrI.gtf` files must be located in the `data/` directory before running the pipeline.

## 5. Running the pipeline

Open a terminal and navigate to the project root directory, `dna2protein`:

```bash
cd /path/to/dna2protein
```

Activate the environment:

```bash
conda activate dna2protein
```

Then run:

```bash
bash run_all.sh
```

The `run_all.sh` script executes the following steps in sequence:

1. Deletes the existing `results` directory and creates a new one.
2. Runs `step1_stats.py` and `step3_all_genes.py` to calculate chromosome statistics and extract and record genes.
3. Runs `step4_proteins.py` to translate CDS sequences into proteins.
4. Creates a protein database with `makeblastdb` and performs all-against-all comparisons with `blastp`.
5. Runs `step5_blast_filter.py` to filter the BLAST results.
6. Runs `step6_plots.py` to generate the plots.

**Warning:** `run_all.sh` includes the `rm -rf results` command. Every time it runs, it deletes the existing `results` directory and all of its contents before recreating it. Save any results you want to keep elsewhere.

## 6. Generated results

The results are stored in the `results/` directory. Based on the project steps, they include:

- Chromosome statistics, including length, frequencies of bases A/C/G/T, and GC percentage.
- FASTA files containing the extracted coding sequences (`cds.fa`) and translated proteins (`proteins.fa`).
- Tables with gene and protein information.
- The BLAST database and the raw results file `blast_all_vs_all.tsv`.
- Filtered BLAST results, according to the implementation in `step5_blast_filter.py`.
- A GC-content plot across the chromosome length using 5,000-base windows.
- A histogram of protein-length distribution.

The exact names of the tables, filtered results, and images are defined by the corresponding Python scripts.

## 7. Reproducibility

To verify that the pipeline can generate the results from scratch:

1. Run `bash run_all.sh`.
2. Check the files generated in the `results/` directory.
3. Run `bash run_all.sh` again. The script will delete the previous results and create them anew.
4. Compare the results from the two runs.

Reproducibility requires using the same input files, settings, and compatible tool versions.
